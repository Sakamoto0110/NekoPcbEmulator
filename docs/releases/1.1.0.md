# NekoPcbEmulator 1.1.0

Serial communication is now directly selectable in the launcher. Each board has its own
COM dropdown, limited to the detected emulator-side endpoints configured for the session.
The defaults are PCB-A on COM5 and PCB-B on COM4; external clients use COM6 and COM3 for
the corresponding virtual pairs. TCP and named pipes remain available.

## Changes

- Validate serial availability when powering on, with clear failures for missing or busy ports.
- Preserve independent pipe and COM settings when switching transports.
- Keep ASCII responses in request order when oversized statements and valid commands arrive together.
- Add reusable protocol regression tests, Windows CI, and verified release packaging.
- Document com0com installation risks, Secure Boot/test-signing requirements, and kernel anti-cheat incompatibilities, including the reported Vanguard incompatibility.

## Downloads

- **Self-contained:** includes the .NET runtime; no separate runtime installation is needed.
- **Framework-dependent:** smaller package; requires the .NET 10 Desktop Runtime.

Both Windows x64 ZIP packages include the emulator, reference test client, README, protocol
documents, version, and source commit. `SHA256SUMS.txt` contains archive checksums.

## Validation

CI builds with warnings treated as errors, runs 41 isolated protocol scenarios, then tests
36 wire-level scenarios against each packaged application and checks both reference clients.
Serial tests were also performed locally over COM5/COM6 and COM4/COM3. GitHub-hosted CI
uses TCP and does not install a virtual serial driver.
